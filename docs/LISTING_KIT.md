## Compliance lines (required)

**AI disclosure** — Etsy's Creativity Standards require disclosure in the description for any AI-assisted design, listed under "Designed by". Append where applicable:

> This design was created by me using AI-assisted tools from my own original prompts, then refined by hand. The Arabic calligraphy has been checked for accuracy by a native Arabic reader.

**Listing setup:** who made it = "I did" · what is it = finished product · when = "Made to order" (physical) / digital file (downloads).

**Never claim:** bestseller status, review counts, ratings, "limited edition" runs, or sales figures you don't have. (UK DMCC Act and US FTC rule both ban fabricated social proof.)
