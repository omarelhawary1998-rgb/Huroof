# Click-by-click — set up & link every Huroof account

> Read `docs/SOCIAL_PROFILES.md` alongside this guide. Every piece of text
> you need to paste is already there.

The plan in one line:
**Etsy + Payhip are the shops. Pinterest + Instagram + TikTok send free
visitors to those shops.** We set them up in that order.

---

## A) Etsy — finish the shop (15 min)

1. Go to **etsy.com** → log in → click **Shop Manager** (top right).
2. Click **Settings** → **Info & appearance**.
   - Paste **Shop title** from `SOCIAL_PROFILES.md §1`.
   - Paste **Shop announcement** in the announcement box.
   - Add a shop icon (use `products/pins/01-bismillah-pin.png`) and a banner
     (any of the framed mockups in `products/mockups/`).
3. Click **About your shop** → paste the **About → Story** block. Add 2–3
   photos (use any framed mockups).
4. Click **Settings → Options → Message to buyers** → paste the digital
   buyers message.
5. Click **Settings → Offsite Ads** → **OFF** (you're allowed to while small;
   this saves the 12% offsite ads fee).
6. **Shop sections** (left sidebar on the listings page) — create the 7
   sections listed in `SOCIAL_PROFILES.md §1`.

---

## B) Payhip — finish the store (10 min)

1. Go to **payhip.com** → log in → **Account → Store settings**.
   - Paste **Store name** and **tagline**.
2. **Store page → About** → paste the long description.
3. **Store page → Social links** → paste each social URL into its slot.
4. **Account → Business details** → use the answers in
   `docs/PAYHIP_BUSINESS_ANSWERS.md` (you've already pasted these once).
5. **Payouts** → confirm bank details and tax settings are saved.

---

## C) Pinterest Business (15 min) — biggest free-traffic source

1. Go to **pinterest.com** → **Sign up** → choose **Business account**.
2. **Settings → Edit profile**:
   - Display name, username, bio — copy from `SOCIAL_PROFILES.md §3`.
   - Upload `products/pins/01-bismillah-pin.png` as profile photo (crop to
     the artwork area).
3. **Settings → Claimed accounts → Claim website**:
   - Paste `https://omarelhawary1998-rgb.github.io/Huroof/`.
   - Choose **HTML tag** option. Send the meta tag here in chat and I'll
     add it to `index.html` for you.
4. **Create the 8 boards** listed in `§3`. Use the exact names + descriptions.
5. **Upload pins** — pick a pin from `products/pins/` (core 8) or
   `products/pins/batch1/` (30 batch-1 pins). In the **Destination link**
   field paste either the Etsy listing URL or the Payhip product URL for
   that design.
6. Pace: **5–10 pins per day** for the first 30 days. Pinterest rewards
   consistency, not bursts.

---

## D) Instagram Business (10 min)

1. Open the Instagram app → **Sign up** → use email `hello@huroof.co`.
2. **Profile → Edit profile → Switch to professional account → Business**.
   - Category: **Art Gallery**.
3. Paste **Name + Bio** from `SOCIAL_PROFILES.md §4`. Add email contact.
4. **Edit profile → Links → Add external link**:
   - Add Payhip URL as primary link.
   - Add Etsy URL as second link (Instagram shows both).
5. First 9 posts: use any 9 framed mockups from `products/mockups/`. Each
   caption ends with: `Shop — link in bio.`

---

## E) TikTok Business (5 min)

1. tiktok.com → sign up → **Profile → Settings & privacy → Switch to
   Business account → Art & Crafts**.
2. Paste name + bio from `SOCIAL_PROFILES.md §5`.
3. **Profile → Add link in bio** → Payhip URL.
4. Post 3 simple videos: a phone screen-recording of you scrolling through
   the framed mockups, with one of your own designs as the cover.

---

## F) Cross-link everything (5 min)

So a visitor can hop from any platform to any shop:

| On this page | Add this link |
|---|---|
| Etsy → **About → links** | Pinterest, Instagram URLs |
| Payhip → **Store → Social links** | All 3 social URLs |
| Pinterest → **Settings → Claimed accounts** | Instagram + Etsy |
| Instagram → **Edit profile → Links** | Payhip + Etsy |
| TikTok → **Bio link** | Payhip |

---
